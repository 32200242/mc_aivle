# 3D 모델 자산 사용 주의

현재 포함된 `Female_Adult_01_facial_1024.glb`는 기능 검증용 프로토타입 자산입니다. 코드와 별개로 3D 인물, 텍스처, 원본 FBX/GLB의 라이선스 조건을 반드시 확인해야 합니다.

공공·교육 서비스의 외부 배포 전에는 다음 증빙을 별도로 보관하세요.

- 원 저작권자와 다운로드 출처
- 이용약관 또는 라이선스 원문과 확인 일자
- 수정·재배포·웹 서비스 제공·상업적 이용 허용 여부
- 실제 특정 인물의 초상 또는 생체정보를 사용하지 않았다는 확인
- 제3자 텍스처·의상·모션의 별도 라이선스

조건이 불명확하면 현재 모델을 공개 서비스에 포함하지 말고, 기관이 직접 제작·구매해 재배포권을 확보한 GLB 또는 명시적 CC0 자산으로 교체해야 합니다. 모델 교체 시 코드 변경은 `NEXT_PUBLIC_AVATAR_MODEL_URL`과 필요한 뼈/morph 별칭 추가로 제한됩니다.
